📋 Quick Setup Steps

1. Open console.cloud.google.com
2. Create project → Enable Google Sheets API
3. Create OAuth 2.0 credentials (Web App type)
4. Add your app URL to authorized JS origins
5. Create a Google Sheet, copy its ID
6. Share that sheet with all salespeople (Editor)

See SETUP_GUIDE.md for detailed steps with screenshots.
